/* 1 · Каллиграфический draw-on скрипта */
.script{clip-path:inset(0 0 0 0)}
.script.play{animation:draw 2.4s cubic-bezier(.22,.61,.36,1) both}
@keyframes draw{from{clip-path:inset(0 100% 0 0)}
                to{clip-path:inset(0 0 0 0)}}
/* prod: скрипт в single-line SVG + stroke-dashoffset
   для настоящего «пера» */
/* 2 · Champagne-foil sweep (hover, тактично) */
.foil{position:relative;overflow:hidden}
.foil::after{content:"";position:absolute;inset:0;
 background:linear-gradient(110deg,transparent 42%,
  rgba(196,177,150,.6) 50%,transparent 58%);
 background-size:220% 100%;background-position:220% 0;opacity:0}
.foil:hover::after{opacity:1;animation:sweep 1.15s ease-out}
@keyframes sweep{to{background-position:-60% 0}}
/* 3 · Descriptor — fade + раскрытие трекинга */
.desc.play{animation:descIn 1.3s ease-out 1s both}
@keyframes descIn{from{opacity:0;letter-spacing:0}
                  to{opacity:1;letter-spacing:8px}}
/* 4 · Keystone draw + monogram rise */
.keystone path{stroke-dasharray:240;stroke-dashoffset:240;
 animation:dash 1.6s ease-out .2s both}
@keyframes dash{to{stroke-dashoffset:0}}
.mono.play{animation:rise 1.1s cubic-bezier(.22,.61,.36,1) both}
@keyframes rise{from{opacity:0;transform:translateY(16px) scale(.96)}
                to{opacity:1;transform:none}}

Тайминги: 1.1–2.4s, ease-out, задержки каскадом. Уважать prefers-reduced-motion: отключать draw/sweep, оставлять fade.

04 — Правила

Clear-space · Min-size · Do & Don'ts

Охранное поле · Min-size

  • Поле = высота «M» вордмарка (1×).
  • Скрипт-логотип: min-ширина 140px / 34 мм.
  • Вордмарк: 96px · Монограмма: 16px (фавикон).
Maison IU
✓ DO
  • Скрипт — hero/упаковка/сертификаты; вордмарк — UI/мелкое; монограмма — бот/фавикон.
  • Монохром по умолчанию; Garnet и шампань — только акцент/фольга.
  • Много воздуха, медленный motion.
✕ DON'T
  • Не ставить скрипт на мелком (там монограмма).
  • Не заливать логотип золотом/жёлтым, не в жирный круг.
  • Не растягивать, не менять трекинг, не добавлять тени.

09 — Motion-принципы

Медленно и весомо

Ease

ease-out, 1.1–2.4s. Никаких bounce/резких.

Reveal

Каскад: скрипт draws → вордмарк rise → дескриптор трекинг.

Champagne

Foil-sweep только на hover ключевого, тактично.
